VEX IQ Prosthetic Leg Brace

I designed and built a prosthetic leg brace using VEX IQ robotics components to explore how engineering can assist people with limited leg mobility. The prototype uses motor-driven gear mechanisms to support knee and ankle movement, with motor encoders helping control joint positioning. I also adjusted the gear ratios and reinforced the frame to improve movement and stability.

I presented this project at the HOSA State Leadership Conference in Exploring Medical Innovations, where I earned **2nd place and qualified for the international competition**.
